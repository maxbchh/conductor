# Conductor

Новая кассовая система кондуктора. Проект создан с нуля; репозиторий Ticket остаётся нетронутым.

## Стек
- Vanilla JavaScript, HTML и CSS
- Supabase (Postgres + Data API)
- GitHub Pages

## Развёртывание
Включите GitHub Pages для ветки `main`, корневая папка `/`.

## База данных
SQL-схема таблиц кассы, смен, билетов и текстового архива расписаний находится в `supabase/schema.sql`.
Перед запуском выполните SQL в Supabase SQL Editor. Параметры подключения находятся в `app.js` и используют publishable key отдельного проекта Conductor, в отдельной таблице `conductor_*`. Секретные ключи в клиент не добавляются.

## Возможности
- Продажа билетов с расчётом по числу остановок
- Полный / льготный / школьный тариф
- Наличные с быстрыми суммами и расчётом сдачи, виртуальные карты с изменяемым балансом
- Открытие смены до назначения маршрута, временный автобус вручную
- QR-ссылка на отдельную страницу телефона для выбора маршрута, остановки и игровой оплаты
- Маршруты с остановками через точку с запятой и поддержка неполного рейса
- Мини-билет 42 мм шириной на рулоне 58 мм
- Редактор маршрутов, автобусный парк, смены и игровое время
- Запись билетов и рейсов в Supabase


## Важно перед первым запуском
1. Откройте Supabase SQL Editor нового проекта Conductor.
2. Выполните SQL из `supabase/schema.sql`. Он создаёт отдельные таблицы Conductor и архив расписаний. Маршруты и парк добавляются вручную.
3. Включите GitHub Pages для ветки `main` / GitHub Actions. Workflow проверяет синтаксис JavaScript и публикует сайт.

**Режим доступа:** приложение пока работает без входа в аккаунт, поэтому политики таблиц разрешают чтение и запись через публичный клиентский ключ. Используйте эти таблицы только для игровых данных; не храните здесь личные данные и платёжные реквизиты. Для закрытого доступа потребуется добавить авторизацию.

Пока SQL из `supabase/schema.sql` не выполнен, касса не сможет загрузить справочники и сохранить билеты.
