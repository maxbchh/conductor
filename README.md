# Conductor

Новая кассовая система кондуктора. Проект создан с нуля; репозиторий Ticket остаётся нетронутым.

## Стек
- Vanilla JavaScript, HTML и CSS
- Supabase (Postgres + Data API)
- GitHub Pages

## Развёртывание
Включите GitHub Pages для ветки `main`, корневая папка `/`.

## База данных
SQL-схема и перенос существующих автобусных маршрутов/подвижного состава находятся в `supabase/schema.sql`.
Перед запуском выполните SQL в Supabase SQL Editor. Параметры подключения находятся в `app.js` и используют publishable key старого проекта Supabase, в отдельной таблице `conductor_*`. Секретные ключи в клиент не добавляются.

## Возможности
- Продажа билетов с расчётом по числу остановок
- Полный / льготный / школьный тариф
- Наличные с быстрыми суммами и расчётом сдачи, условная оплата картой
- Мини-билет 42 мм шириной на рулоне 58 мм
- Редактор маршрутов, автобусный парк, смены и игровое время
- Запись билетов и рейсов в Supabase
